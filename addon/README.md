# Trouveur

Add-on Home Assistant : propositions de films selon vos critères, avec la
disponibilité sur votre serveur Plex, vos plateformes de streaming et votre
tracker.

Interface intégrée à la barre latérale (ingress). Données dans `/data`, donc
conservées d'une mise à jour à l'autre et incluses dans les sauvegardes.

Voir [DOCS.md](DOCS.md) pour l'installation, la configuration et la reprise de
listes existantes.
